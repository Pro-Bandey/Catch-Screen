# Catch-Screen

Impressive screenshot tool lets users can take full page screen capture selected page screen capture and edit screenshot.


* Crop and paint over
* Add arrows and captions
* Insert text

## 🚀 Quick Screen Capture
Make a full webpage screen capture or select any specific part. Once captured, you can:

   1. Edit the image
   2. Save and download it directly to your PC
   3. Add text or graphic elements

The app is launched directly from your browser to save time. Simply click the extension icon to choose between a whole page capture, visible page or a selected part. There are no additional windows or external websites—just the screenshot you need.
------------------------------

## This tool offers:

* ✔️ Full Page Capture.
* ✔️ Visible Page.
* ✔️ One-Click Ease: Screenshots in a single click.
* ✔️ Privacy Focused: Storage and processing happen locally without a server.
* ✔️ Fast Export: Save as PNG or copy to your clipboard instantly.
* ✔️ No Barriers: No login, registration, or file size restrictions.
* ✔️ Flexible Editing: Add shapes (pointers, arrows, squares) or discard changes easily.

------------------------------
## 🛠️ How It Works

   1. Click the extension icon in the upper right corner of your browser.
   2. Select your capture option.
   3. The tool will capture the page and open it in a new tab.
   4. Edit your image and upload it to your PC.

## 📝 Notes

Important: Remember to reload the page after you install the extension before trying to take a screenshot. Chrome needs to initialize the extension for each page to work correctly.
